=========================
smash 1.3.0 Release Notes
=========================

The smash 1.3.0 release adds several new functionalities and fixes compatibility issues, including:

- ``Descriptor transformation``
    It is now possible to specify the transformation applied to descriptors. The previous behavior, which normalizes descriptors between 0 and 1, remains the default. It is now also possible to keep descriptors unchanged or to standardize them.
    This can be configured through the ``descriptor_tfm`` argument in ``setup``.

- ``New hybrid flux correction structures with rain intensity``
    Two new hybrid structures have been added: ``gr4_ri_mlp_exc`` and ``gr5_ri_mlp_exc``. These hybrid structures only correct the exchange flux and account for rain intensity.
    These structures are available through the ``hydrological_module`` argument in ``setup``.

- ``Zero routing module``
    A new routing module, ``zero``, has been added. By definition, this module performs no routing and directly returns the elementary discharge. It can therefore be used to facilitate coupling with external routing models.
    The new routing module is available through the ``routing_module`` argument in ``setup``.

- ``Backward run``
    A new model method, ``backward_run``, has been added. It computes the transposed Jacobian multiplied by the cotangent vector of either the cost function or the routed discharge.
    See the `smash backward_run API documentation <https://smash.recover.inrae.fr/api_reference/principal_methods/smash/smash.Model.backward_run.html>`_ for more information.
